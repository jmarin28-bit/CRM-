# Reglas del Proyecto (Custom Rules)

Esta carpeta `.agents/rules/` contiene archivos de reglas específicas para modularizar la guía y comportamientos del asistente IA en **Ioncore CRM3 V4**.

## Reglas disponibles
- `AGENTS.md`: Archivo maestro de memoria persistente ubicado en la raíz de `.agents/`.
- Puedes agregar archivos `.md` adicionales aquí con reglas específicas para áreas del proyecto (ej. `ui_rules.md`, `api_rules.md`, `database_rules.md`).
